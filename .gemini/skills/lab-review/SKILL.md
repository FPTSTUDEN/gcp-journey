# Review a lab record

1. Read `TAXONOMY.md`, `GEMINI.md`, and the target lab record.
2. Check whether the tags communicate useful distinctions across topic, skill, service, and context. Do not insist that every group be populated.
3. Recommend per-tag evidence ranks from 1–3. Focus on what the lab actually exercises, not length or command count.
4. Make reasonable inferences from the lab description. Flag only uncertainty that could change the interpretation; don't block on missing optional details.
5. Keep the record concise. Suggest edits directly when asked, and explain meaningful changes in a short note.
6. Treat rankings and tags as recommendations. The user owns final interpretations and can accept, edit, or reject them.
7. Do not infer that the user personally performed a task just because the lab describes it.
