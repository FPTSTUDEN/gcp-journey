# Review a lab record

1. Read `TAXONOMY.md`, `GEMINI.md`, and the target lab record.
2. Check that every tag is in the correct group:
   - concept -> topic
   - action/capability -> skill
   - product/technology -> service
   - larger system/problem setting -> context
3. Prefer existing taxonomy labels. Flag likely synonyms and overly broad tags.
4. Assess every tag independently using the 1–3 scale in `TAXONOMY.md`.
5. Make sure each rank has specific supporting evidence. If the record does not prove hands-on activity, lower the rank or mark it unverified.
6. Do not infer learner mastery from course completion.
7. Keep the record concise. Do not expand it into a full lab tutorial.
8. Return a proposed diff or a concise list of changes before making broad taxonomy changes.
