# Maintain the catalog

1. Read `TAXONOMY.md` and `GEMINI.md`.
2. Scan lab records and look for duplicate tags, useful emerging contexts, missing links, and patterns across labs.
3. Prefer consistency, but don't force-fit a lab into an existing tag when the distinction matters. Suggest taxonomy changes with a brief rationale.
4. When asked to update indexes, derive counts from the records. Distinguish lab frequency from evidence rank.
5. Present meaningful proposed changes for user review before bulk-renaming tags or rewriting prior judgments.
6. Treat generated summaries as a view of the current records, not as an objective measurement of permanent mastery.
