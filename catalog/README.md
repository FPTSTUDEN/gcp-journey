# Catalog

This directory is intended for generated indexes, not the source of truth.

Suggested first generated views:
- `labs.md`: all labs with title, date, and tags
- `tags.md`: each tag, number of labs, rank distribution, and contexts
- `context-map.md`: contexts and the topics/services/skills associated with them

For the first version, these files can be updated manually. Add a script only when manual updates become annoying.
